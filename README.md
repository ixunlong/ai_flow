# AI协作工作流系统

## 项目简介

这是一个全AI协作的工作流系统，通过多个AI角色的协同工作，完成从需求收集到产品交付的完整流程。用户只需通过与AI对话，即可推动项目的各个阶段，无需亲自编写文档或代码。

## 系统架构

### 核心理念

- **角色分离**：每个AI在独立的对话上下文中担任特定角色
- **目录隔离**：每个角色只能访问和修改自己的目录
- **Kanban管理**：每个角色使用看板系统管理任务流程
- **持续优化**：元工作流负责整体系统的迭代和改进

## Kanban工作流

每个角色都使用统一的五阶段看板：

1. **Backlog（需求池）**：原始想法、待评估的需求
2. **In Progress（进行中）**：正在执行的任务
3. **In Testing（测试中）**：已完成待验证的任务
4. **In Deployment（发布中）**：已测试待部署的任务
5. **Released（已归档）**：已完成的任务，按日期归档

## 使用方式

### 1. 配置项目类型

首先编辑 `project-config.md`，说明当前项目类型（创作小说、游戏开发、App开发等）。

### 2. 与各角色对话

在VSCode中为每个角色创建独立的Copilot对话：

- **元工作流对话**：用于优化和调整整个系统
- **产品经理对话**：讨论需求和产品设计
- **技术经理对话**：进行技术实施
- **测试工程师对话**：执行测试和质量保证
- **交付工程师对话**：完成部署和上线

### 3. 工作流程

```
用户想法 → 产品经理 → 技术经理 → 测试工程师 → 交付工程师 → 完成
            ↓            ↓           ↓            ↓
         产品文档     技术实现    测试报告     上线部署
```

### 4. 持续优化

定期与元工作流对话，分析工作效果，调整角色定位、流程设计和文件结构。

## 核心优势

- ✅ **零编码负担**：用户只需对话，不写代码或文档
- ✅ **专业分工**：每个AI专注自己的专业领域
- ✅ **上下文隔离**：避免信息混乱和角色混淆
- ✅ **流程可追溯**：完整的看板和日志系统
- ✅ **持续进化**：元工作流不断优化系统本身

## 开始使用

1. 查看并编辑 [project-config.md](project-config.md)
2. 阅读各角色的提示词文件（每个目录下的 `prompt.md`）
3. 在VSCode中为每个角色创建独立的Copilot对话
4. 开始与产品经理对话，提出你的第一个想法！
