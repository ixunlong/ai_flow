# 技术文档

存放技术设计文档和架构文档。

## 文档类型

### 技术设计文档（TDD）
- `TDD-XXX-功能名称.md` - 具体功能的技术设计
- 对应每个PRD，描述如何技术实现

### 架构文档
- `architecture.md` - 整体系统架构
- `技术选型说明.md` - 技术栈选择理由
- `开发规范.md` - 代码/内容规范

### 实现文档
- `implementation-notes.md` - 实现过程记录
- `troubleshooting.md` - 问题排查指南

## 使用模板

使用 `A-MetaWorkflow/templates/技术设计文档模板.md` 创建新TDD。
