# 对话日志

此目录记录与用户的每次对话摘要。

## 日志格式

文件名：`YYYY-MM-DD-对话主题.md`

## 日志模板

```markdown
# 对话日志 - 主题

**日期**: YYYY-MM-DD  
**时间**: HH:MM  
**参与者**: 用户 & 元工作流AI

## 对话摘要
（简要描述本次对话的核心内容）

## 关键决策
1. 决策1的描述
2. 决策2的描述

## 文件变更
- 新增: 文件路径列表
- 修改: 文件路径列表
- 删除: 文件路径列表

## 任务变动
- 新增任务: TASK-XXX
- 完成任务: TASK-XXX
- 调整任务: TASK-XXX

## 经验总结
（本次对话的收获、发现的问题、改进方向）

## 待办事项
- [ ] 下次需要处理的事项1
- [ ] 下次需要处理的事项2

## 用户反馈
（用户对系统的意见和建议）
```

## 日志分析

定期回顾日志可以：
- 识别重复出现的问题
- 总结用户的使用习惯
- 发现系统改进机会
- 追溯重要决策的背景
